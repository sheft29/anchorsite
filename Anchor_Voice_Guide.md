# Anchor — Voice & Content Guide

## Reference point
Between The School of Life and a good New Yorker newsletter — but warmer and more actionable. Never clinical, never corporate, never like a wellness app.

## The voice is:
- **Warm** — like a thoughtful friend, not a brand
- **Specific** — concrete images and details, not vague uplift
- **Curious** — invites reflection, doesn't lecture
- **Non-prescriptive** — offers, never commands
- **Editorially grounded** — feels researched and considered, not generated

## Hard rules (apply everywhere — UI copy, notifications, entries, empty states)

- **No em dashes.** Use periods, commas, or restructure the sentence.
- **No AI syntax patterns.** Avoid "It's not just X, it's Y," "Let's dive in," "unlock," "journey," "elevate," listicle throat-clearing, and anything that reads like generated copy.
- **No shame mechanics.** No guilt language, no red/failure states, no "you missed a day" framing.
- **No streaks.** No streak counters, no loss-aversion nudges, no "don't break the chain."
- **Life-context sensitivity.** Copy should never assume a good day. Avoid language that only works if things are going well (hard weeks, travel, grief all need room).

## Applies beyond daily entries
This guide governs the daily publication AND all app copy: onboarding, push notifications, button labels, empty states, error messages, Compass/weekly review language. If a screen has text on it, it follows this guide — no separate "app voice."

## Clinical vs. plain language
Anchor is grounded in ACT, Big Five/OCEAN, positive psychology, and CBT — but the person using it should never see clinical terminology.
- Clinical language (framework names, scoring, diagnostic-sounding phrasing) stays in **internal docs and the About page only**.
- In-product language is always warm and plain. E.g., Big Five insights get delivered as narrative sense-making ("You tend to notice details others miss"), never as raw trait scores or labels.

## Quick self-check before shipping any copy
1. Would a thoughtful friend actually say this?
2. Does it assume the reader is having a good day?
3. Could this be mistaken for AI-generated filler?
4. Is there an em dash, a streak, or a shame cue hiding in it?

If yes to the last two, rewrite.
