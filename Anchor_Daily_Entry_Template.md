# Anchor — Daily Entry Template (Locked Structure)

This is the fixed structure for every daily entry — in the email publication now, and inside the Journal page in the app later. Order does not change; sections can be collapsed/expanded in the app UI, but all six must be present.

## 1. Opening Quote
Sets the tone for the entry. Should connect thematically to the day's throughline, not be generic inspiration.

## 2. Worth Knowing Today
A short piece of research, history, or idea. Must **build a logical arc toward a clear, memorable conclusion** — not a list of isolated facts, not trailing off. Think: sets up a question, walks through it, lands somewhere.

## 3. Today's Media
One artwork. Title, artist, and one sentence of context.
- Selection is a high editorial priority — must be **philosophically precise**, chosen because it illustrates the day's idea, not decorative or "nice to look at."
- Example: Magritte's *Not to be Reproduced* was used for an entry about the observer-self.

## 4. Today's Anchor: Peace / Stability / Expression
One pillar is spotlighted per entry, rotating.
- **Critical rule: the pillar entry must be thematically independent** — it should not just restate or vary the research theme from section 2. It's a separate idea, connected only by the day's overall thread.

## 5. Reflection Question
One open question tied to the day's theme. Should invite genuine thought, not have an obvious "right" answer.

## 6. Today's Wildcard
A rotating format slot — this is NOT a media recommendation (that's section 3's job). Wildcard varies: could be a prompt, a small challenge, a question, an exercise. Keeps the format from feeling templated.

## Notes for engineering
- This structure maps directly to the Journal page's entry accordion (Quote / Worth Knowing / Today's Media / Peace / Stability / Expression / Wildcard) — see status doc Journal Page render.
- All sections should follow the Voice & Content Guide.
- All three pillar sub-sections (Peace / Stability / Expression) are required every entry. None should ever be missing or blank.
